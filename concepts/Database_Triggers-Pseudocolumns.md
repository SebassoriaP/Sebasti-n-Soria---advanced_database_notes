# Topic 1 Database Triggers and Pseudocolumns

## My understanding
- Triggers are automatic actions executed when a database event occurs.

## Why it matters
- They help enforce rules and automate logic inside the database.

## Example
Trigger that updates a timestamp before insert.


# Topic 2 Database Pseudocolumns

## My understanding
- Pseudocolumns are special values provided by the database like USER or SYSDATE.

## Why it matters
- They allow access to system information without storing it manually.

## Example
USER returns the current database user.
