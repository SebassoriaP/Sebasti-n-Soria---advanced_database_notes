# Session – Introduction to SQL (Lessons 1–5)

## Topics covered

Basic SELECT statements to retrieve data from a table.

Selecting specific columns or all columns using *.

Filtering data using WHERE.

Using comparison operators such as =, !=, <, <=, >=.

Using logical operators like AND, NOT, and BETWEEN.

Filtering text using LIKE and wildcards.

Removing duplicates using DISTINCT.

Sorting results using ORDER BY.

Limiting results with LIMIT and OFFSET.

Introduction to subqueries.

---

## What I understood

- SELECT is used to retrieve data from a table.
- WHERE filters rows based on conditions.
- LIKE helps search for patterns in text.
- DISTINCT removes duplicate results.
- ORDER BY sorts the output.
- LIMIT and OFFSET help control pagination.
- Subqueries allow us to use the result of one query inside another.

---

## What is still confusing

- When to use subqueries instead of joins.
- The difference between == and = depending on the SQL engine.
