## Topics covered
A JOIN is used to combine data from two or more tables using a related column. It helps connect information that is stored separately in a database.

An INNER JOIN returns only the rows that match in both tables. If there is no match, the row is not included in the result.

A LEFT JOIN returns all rows from the left table and the matching rows from the right table. If there is no match, the result shows null values for the right table.

A RIGHT JOIN returns all rows from the right table and the matching rows from the left table. If there is no match, null values appear on the left side.

A CROSS JOIN generates all possible combinations between rows of two tables. It creates a cartesian product and does not need a condition because every row is combined with every row.

A SELF JOIN is when a table is joined with itself. It is useful to compare rows within the same table, such as employees and their managers.

An OUTER JOIN returns rows even if there is no match between tables. A FULL OUTER JOIN returns all rows from both tables and fills missing matches with null values.
