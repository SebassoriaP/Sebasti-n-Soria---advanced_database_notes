## Topics covered

Aggregate Functions are used to summarize data from multiple rows into a single result.

COUNT counts the number of rows.

SUM adds all numerical values in a column.

AVG calculates the average value of a column.

MIN returns the smallest value in a column.

MAX returns the largest value in a column.

DISTINCT removes duplicate values before applying an aggregate function.

GROUP BY divides the data into groups so aggregate functions can be applied to each group separately.

HAVING is used to filter results after grouping.

---

## What I understood

- Aggregate functions summarize data into one result.
- COUNT can count total rows or non-null values.
- SUM and AVG are used for totals and averages.
- GROUP BY is necessary when we want results per category.
- HAVING filters grouped results.
- WHERE filters rows before grouping.
