# Session – 2026-04-23

## Topics covered

* Database transactions.
* COMMIT and ROLLBACK operations.
* How transactions group multiple operations into a single unit.
* Updating data within a transaction.

## What I understood

* A transaction is a group of operations that must be executed together as a single unit.
* COMMIT permanently saves all changes made during the transaction.
* ROLLBACK undoes changes if an error occurs before the transaction is committed.
* UPDATE statements can modify data as part of a transaction.

## What is still confusing

* When a transaction starts automatically and when it needs to be explicitly controlled by the user.
